# Vad är HTML?
HTML står för HyperText Markup Language och är ett språk som konstruerar samt skapar en struktur av innehållet på en webbplats. Detta språk definierar även hur bilder, texter, länkar osv, ska se ut, alltså ett MarkUp-språk.
## Varför HTML?
* Lättare språk och enklare för nybörjare
* Den fungerar i alla webbläsare
* Webbplatsernas ryggrad
